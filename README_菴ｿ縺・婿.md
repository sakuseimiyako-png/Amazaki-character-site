# 『物語之終幕』サイト試作 v1.0

## 収録
- `index.html` 表示構造
- `styles.css` 配色・レスポンシブデザイン・演出
- `app.js` 5秒ごとのスライド、タッチスワイプ、全画面メニュー、形態切り替え、検索、項目編集、JSONバックアップ
- `data/content.json` 公式キャラ情報の**要約・名称一覧を含む初期データ**
- `assets/` 提供された画像15枚、動画2本（menu-reference.mp4は参考映像でサイト未使用）

## 重要な限界
この納品は**静的サイト＋この端末だけで動く編集プロトタイプ**。パスワード認証、外部DBへの公開保存、画像そのもののアップロード、完全ZIPバックアップ、リッチテキスト編集、一般公開先への編集反映は未実装です。無認証の編集ボタンは公開ページ上に存在するものの、変更は閲覧者のブラウザのlocalStorage内だけ。公開データは変更されません。本番用の管理画面だと誤認しないでください。

能力・装備・技の**詳細説明は元の会話の全文から要約／未転記**の状態です。名前・概要の一覧を確認し、次回に全文を転記してください。空欄、機密名██████、模倣魔術等は勝手に創作していません。

## ローカル起動（Windows例）
1. ZIPをすべて展開（ZIP内のまま起動しない）。
2. Pythonが入っているPCで展開先のフォルダを開く。
3. アドレスバーへ `cmd` と打ってコマンドプロンプトを起動。
4. `python -m http.server 8000`（環境により `py -m http.server 8000`）を実行。
5. ブラウザで `http://localhost:8000` を開く。終了はコマンド画面で Ctrl+C。

`index.html` を直接ダブルクリックするだけではブラウザのセキュリティ制約によって `data/content.json` が読み込めないことがあります。

## 操作
- ロード動画は終了時、または最大6.5秒で自動終了。SKIPで先に進める。
- メイン画面は5秒で切替。左右の矢印／ドット／スマホ左右スワイプで手動変更。
- `SCROLL TO DISCOVER` で説明へ移動。
- 右上の三本線で全画面メニュー。ARSENAL / ARCHIVE を押して下位項目を展開。
- 「通常形態」「覚醒形態」で立ち絵・能力説明・異能道具一覧が変更。
- メニュー最下部の「管理・データ編集（この端末のみ）」から試作編集画面へ。
- 「JSONを書き出す」で文章・記事の保存（画像は含まない）。復元はJSONを貼り付けてボタンを押す。復元前の状態もJSONとしてダウンロードされる。

## GitHub + Vercel 公開（閲覧機能のみ）
1. GitHubで新規リポジトリを作成。解凍したこのフォルダの**中身**をルートにアップロードする。
2. Vercelでそのリポジトリをインポートする。
3. Framework Presetは `Other`、ビルドコマンド不要、出力先はプロジェクトルートのままで公開する。
4. 発行されたURLで表示を確認する。画像の読み込みやスマホのスワイプをテストする。
5. 記事を全員に反映するには、現時点では `data/content.json` をGitHub上で更新し再デプロイする必要がある（ローカル編集は端末にしか保存されない）。
6. Vercel Hobbyプランを用いるなら非商用個人用途などの利用条件を確認する。

## 本番管理の開発方針
- Supabase Auth等の真正な認証、管理者だけが書き込めるRLS、画像ストレージ権限をサーバー側で実装する。
- ローカルストレージは下書き・緊急復旧用とし、公開本文の正本にはしない。
- Tiptapなどのリッチテキストエディタを導入して太字、文字色、下線、見出し、区切り線、演出を安全なデータ構造で保持する。
- 画像アップロード時に5:4/16:9チェック＋トリミング（画質と位置に注意）。
- JSONだけでは削除された画像は戻らない。画像一式とDBデータを同梱したZIPのエクスポート・インポート、暗号化、別保管先を開発する。
- 本番では編集・復元を管理者認証後のみに限定する。
